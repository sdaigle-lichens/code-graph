# code-graph

Code graph extraction and query tool for TypeScript projects using ArangoDB.

## Install

> Not yet published. Use the dev setup below until v0.1.0 ships to npm.

```sh
pnpm i -g code-graph
```

## Dev setup

```sh
git clone <repo>
cd code-graph
pnpm install
pnpm build
pnpm link --global
code-graph --version
```
